# Парсер каталога товаров в Excel

Скрипт собирает данные о товарах (название, цена, описание, картинка, категория, наличие) с сайта `apilearn.tukas.dev` и сохраняет их в Excel-файл.

## Особенности
- Цена берется через API в формате JSON.
- Защита от падения скрипта (обработка сетевых ошибок и битых карточек).
- Цена в Excel записывается как число с валютным форматом (`$`), что позволяет сортировать данные и использовать формулы.

## Установка и запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
2. Запустите скрипт:
   python excel_data.py
3. Результат появится в файле products.xlsx
