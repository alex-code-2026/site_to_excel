# Парсер каталога товаров в Excel

Скрипт собирает данные о товарах (название, цена, описание, картинка, категория, наличие) с сайта `apilearn.tukas.dev` и сохраняет их в Excel-файл.

## Особенности
- Цена берется через API в формате JSON.
- Защита от падения скрипта (обработка сетевых ошибок и битых карточек).
- Цена в Excel записывается как число с валютным форматом (`$`), что позволяет сортировать данные и использовать формулы.

## Установка и запуск (без Docker)

Скачайте проект, откройте терминал в его папке и выполните команды по порядку:

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите скрипт
```bash
python excel_data.py

## Запуск через Docker

Если у вас установлен Docker, выполните следующие команды:

```bash
# 1. Соберите образ
docker build -t my-parser .

# 2. Запустите контейнер (файл products.xlsx появится в текущей папке)
```bash
docker run --rm -v "%cd%:/app" my-parser

Для пользователей Mac/Linux:
Команда запуска контейнера выглядит немного иначе:

docker run --rm -v "$(pwd):/app" my-parser
